# Contributors

This fork records both code assistance and physical-device verification.

- **Shimakaze** — project direction, release decisions, physical-device
  testing, reproduction, and feedback.
- **DeepSeek AI ([@deepseek-ai](https://github.com/deepseek-ai))** —
  AI-assisted code and documentation contributions developed through Codex
  Desktop using the DeepSeek V4.1 flash 1017 model.
- **Skyward upstream contributors** — the original project and all inherited
  work; see <https://github.com/kirklin/skyward/graphs/contributors>.

AI-assisted changes are reviewed and validated as far as stated in
`FEATURES_CRUX.md` and `FEATURES_CRUX.zh-CN.md`. A feature is not described as
verified unless Shimakaze actually tested it on the physical device.

# 贡献者

本 Fork 同时记录代码协作和真机验证责任。

- **Shimakaze**：项目方向、发布决策、人工真机测试、问题复现与反馈。
- **DeepSeek AI（[@deepseek-ai](https://github.com/deepseek-ai)）**：
  通过 Codex Desktop 使用 DeepSeek V4.1 flash 1017 模型完成的 AI 辅助代码
  与文档贡献。
- **Skyward 上游贡献者**：原项目及其全部继承工作，见
  <https://github.com/kirklin/skyward/graphs/contributors>。

AI 辅助修改只按 `FEATURES_CRUX.md` 和 `FEATURES_CRUX.zh-CN.md` 中写明的
范围视为已验收。没有经过 Shimakaze 真机实际测试的功能，不会标记为“已真机
验证”。
